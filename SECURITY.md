# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub's [private vulnerability reporting](https://github.com/rafaelfqueiroz/farol-de-leiloes/security/advisories/new). Include what you found, how to reproduce it, and what data or accounts it could affect. You will get an acknowledgement within 5 business days.

Please do not access, modify or keep data that is not yours while investigating, and do not run automated scans against production.
