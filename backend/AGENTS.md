# Repository Guidelines

## Project Structure & Module Organization
- Source: `src/` (NestJS). Entry: `src/main.ts`, root module: `src/app.module.ts`.
- Auctions domain: `src/auctions/` with `*.module.ts`, `*.controller.ts`, `*.service.ts`, `schemas/` and `importer/` (downloader, parser, scheduler).
- Shared utilities: `src/common/`.
- Tests: `test/` (Jest), fixtures in `test/fixtures/`.
- Build output: `dist/` (generated by `npm run build`).

## Build, Test, and Development Commands
- `npm run start:dev`: Run in watch mode with `ts-node-dev`.
- `npm run build`: Compile TypeScript to `dist/` via `tsc`.
- `npm start`: Start compiled app (`node dist/main.js`).
- `npm run start:debug`: Start with inspector on port 9229.
- `npm test`: Run Jest tests (Node environment, `test/**/*.spec.ts`).

## Coding Style & Naming Conventions
- Language: TypeScript (Node 18+). Indentation: 2 spaces; use semicolons and single quotes.
- NestJS patterns: classes `PascalCase` (e.g., `AuctionsService`), functions/vars `camelCase`, constants `UPPER_SNAKE_CASE`.
- Files: keep Nest naming (`*.module.ts`, `*.service.ts`, `*.controller.ts`); directories lowercase (e.g., `auctions`, `common`).
- No linter configured; keep formatting consistent and prefer small, focused functions.

## Testing Guidelines
- Framework: Jest with `ts-jest`. Place specs under `test/` as `*.spec.ts`.
- Focus: parser normalization, service upserts, controller query filters. Use `test/fixtures/` where helpful.
- Run tests with `npm test`. Add unit tests for new logic and maintain deterministic behavior.

## Commit & Pull Request Guidelines
- Commits: use Conventional Commits (e.g., `feat(auctions): normalize modality`, `fix(parser): handle BOM`). Keep messages imperative and scoped.
- PRs: include a concise description, linked issue (if any), steps to verify (commands and sample requests), and screenshots/logs when relevant.
- Keep changes small and targeted; include tests for behavior changes.

## Security & Configuration Tips
- Environment: copy `.env.example` to `.env`. Key vars: `MONGODB_URI` and optional `PORT`.
- MongoDB: ensure a reachable database before starting. Default is `mongodb://localhost:27017/auctions`.
- Importer: a scheduled job runs daily at 03:00 and once shortly after startup; be mindful in production.
